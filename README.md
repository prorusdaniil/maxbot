# MAX-бот для пересказа параграфов

Бот на Python предлагает выбрать книгу, загружает указанный параграф из API
`counters.goweb.kz` и пересказывает его простыми словами с помощью официального
Python SDK GigaChat.

## Установка

Требуется Python 3.10–3.13.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Настройка и запуск в PowerShell

Скопируйте пример настроек и внесите свои ключи:

```powershell
Copy-Item .env.example .env
notepad .env
.\.venv\Scripts\python.exe bot.py
```

Впишите в `.env` токен бота MAX и Authorization Key GigaChat. Не добавляйте
реальные ключи в репозиторий: `.env` исключён через `.gitignore`. Без ключа
GigaChat бот запустится, но кнопка пересказа будет недоступна.

Установите доверенный сертификат Минцифры, если этого требует ваша среда для
соединения с MAX/GigaChat.

При `/start` бот показывает демонстрационный список книг. Идентификаторы
`3`, `4` и `5` в `BOOKS` нужно заменить на действительные `bookId` каталога,
который обслуживает внешний API. После выбора книги отправьте номер параграфа.

Бот использует polling для локального запуска. В документации MAX polling
предназначен для разработки и тестирования; для production следует настроить
webhook. Состояние диалога хранится в памяти процесса и сбрасывается при перезапуске.
